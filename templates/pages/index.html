About Freeminer

Freeminer is a Minecraft-inspired sandbox game.

Freeminer is based on Minetest/Luanti which is developed by a number of contributors from all over the globe.

Unlike Minetest/Luanti it aims to make the game fun while trading off some bits of perfectionism.

Unique features

  • 1000000x better view range and name
  • Much closer to infinity world size (±2147483647 blocks in all directions)
  • Dynamic environment: weather, seasons, erosion, growing trees, liquids...
  • 10x faster and more reliable networking.
  • Earth 1:1 mapgen. And some other new core mapgens.
  • Maybe runs even in your browser
  • Multithreaded server.
  • Lan server browser.
